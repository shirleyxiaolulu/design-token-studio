# 落地页功能亮点 · 演示视频

首页（`index.html`）「核心亮点」6 张卡片，鼠标悬停时会**就地播放**对应的演示视频。
把你生成的视频按下面的**文件名**放进本目录（`media/`）即可自动生效，无需改代码。

## 需要的 6 个文件（文件名固定）

| 文件名 | 对应卡片 |
|---|---|
| `feat-generate.mp4` | 一键生成设计规范图 |
| `feat-reskin.mp4`   | 一键换肤 |
| `feat-figma.mp4`    | 直接建好 Figma 变量库 + 样式库 |
| `feat-aijson.mp4`   | AI JSON 即下即用 |
| `feat-darkmode.mp4` | 明暗自动适配 + WCAG |
| `feat-complete.mp4` | 市面上最完整的规范 |

> 还没放视频的卡片，媒体区会显示占位「▶ 演示预览」；放进文件后刷新即生效。

## 视频规格建议

- **比例约 4:3**（悬停时视频会 `object-fit: cover` 铺满整张卡片，卡片约 4:3）。分辨率用 **1280×960**（清晰）或 **800×600**（更小）都行；比例不必精确，cover 会自动裁切居中。
- **格式 mp4 / H.264**（兼容性最好）。
- **静音**：页面以 `muted` 播放（有没有声音都行，页面不会出声）。
- **时长 4–8 秒、能无缝循环**：页面设了 `loop`，循环越顺越好。
- **体积尽量小**（建议每条 < 3MB）：首屏 `preload="metadata"` 只预读首帧，越小越快。
- 录制内容就是该功能在工具里的真实操作（如「输入主色 → 整套规范秒级出现」）。

## 可选：自定义静态封面

默认用视频**首帧**作为悬停前的静态缩略图。若想用单独的封面图，放同名 `.jpg`（如 `feat-generate.jpg`）并告诉我，我给 `<video>` 加上 `poster`。

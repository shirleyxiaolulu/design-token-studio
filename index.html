安装 Figma 插件

插件目前为本地安装（尚未发布到 Figma 社区）。下载后按下面步骤导入即可使用。

下载插件 (.zip) 最新版本 v2.1.0
  1. 下载并解压压缩包，得到 figma-plugin 文件夹。
  2. 打开 Figma 桌面端 → 菜单 Plugins → Development → Import plugin from manifest…
  3. 选择解压出的 figma-plugin/manifest.json。
  4. 在任意文件中按 Cmd + / 搜索「Design System」运行插件。
  5. 在本工具导出 JSON，粘贴进插件 →「同步 Figma 变量」/「生成预览页」。

运行插件后，标题「Design System v2」旁会显示版本号；与上方 v2.1.0 一致即为最新版。需要 Figma 桌面端；网页版不支持开发插件导入。
